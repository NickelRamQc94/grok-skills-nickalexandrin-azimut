# DeepThink — Drive × GitHub

Tu scrutes un estate. Tu ne le remplis pas avec de la mémoire vide.

La métaphore utile : un disque dur inutilisé n'est pas une mémoire active. C'est de l'énergie fantôme, une carte qu'on ne dépense pas. Transférer, ici, veut dire indexer, grader, et n'ouvrir que ce que la passe peut vraiment lire. Ça dure plus longtemps qu'un catalogue recopié.

Ce skill ne remplace pas `deep-scrut-corpus-primaire` (un manuscrit, le texte, pas un inventaire) ni `memoire-chrome-active-dynamique` (orchestration cyclique des 41 dépôts). Ici : triage épistémique de Drive et GitHub, priorités de signal, note NotebookLM que l'humain colle lui-même.

- Traiter « qubit » ou « Willow » comme une preuve d'expérience quantique.
- Traiter un SHA-256 comme une preuve de vérité, de sûreté, ou d'utilité.
- Exécuter `tritbyte_loader.py` ou toute charge base64+gzip intégrée. Syntaxe seule, si demandé : `python3 -m py_compile`, après lecture du fichier.
- Fusionner le pitch Drôles de Maths et le document de travail du 11 novembre. Fusionner le roman du Bloc et le document de campagne.

## Route

1. L'humain nomme **un** manuscrit, ou demande le texte (Timou, Langlois, Quanadec, etc.) → arrêter ici. Suivre `deep-scrut-corpus-primaire`. Un fichier. Le texte. Pas les deux.
2. L'humain demande l'estate, la mémoire Chrome, les liens, les algorithmes, Willow, le pack NotebookLM → rester ici.
3. Les deux dans le même message → faire la route 2 sur l'estate, et nommer **une** porte littéraire. Ne pas ouvrir le manuscrit dans la même passe sauf demande explicite.

## Étiquettes

| Étiquette | Veut dire | Ne veut pas dire |
| --- | --- | --- |
| FAIT | Observé dans cette passe : listing, id, octets, extrait cité. | Vrai dans le monde, complet, sûr. |
| LIM | Limite de la passe : non ouvert, pagination restante, hash seulement. | Échec de l'auteur. |
| DÉF | Définition de travail utilisée pour classer. | Théorème démontré. |

Grades d'œuvre, mêmes que le sibling : P0 lu, P0-pièce (collé, pas de fichier), P1 fichier non lu, P2 titre sans fichier, P3 peut-être noyé, P4 outil. Un P0 sans id reste P0-pièce.

Pour une URL : grade **cité**. Elle devient FAIT seulement si la passe a ouvert la ressource ou son listing.

## Procédure

1. Annoncer le plafond. Exemple : « Cette passe liste N dépôts et ouvre M fichiers. Pas les 116. Pas les 67. »
2. Index public de départ, snapshot pas preuve : [Memoire-Chrome-Active](https://github.com/NickelRamQc94/Memoire-Chrome-Active) — `SOURCES.md`, `SOURCES.json`, `NOTEBOOKLM_SOURCE.md`. Les rouvrir avant de les redire actuels. Détail des ancres : [references/ancres.md](references/ancres.md).
3. Drive : `title_only` ou `exact_name`, un titre à la fois. Paginer. `next_page_token` restant = écrire « pagination non épuisée ». Un `exact_name` vide n'est pas une absence : retenter le titre long.
4. GitHub : `user:NickelRamQc94`, puis le dépôt nommé. Arbre listé = présence. Blob non lu = pas un FAIT de contenu.
5. Priorité, heuristique seulement. Compter dans le **texte ouvert**, pas dans le titre rêvé :

   `algorithme, equation, équation, preuve, proof, qbit, qubit, willow, tritbyte, biosku, sha-256, sha256`

   - 3 signaux ou plus dans un texte ouvert → priorité haute.
   - Liens + hash + structure, sans ces mots → priorité élevée, documentaire.
   - Titre vide de structure, corps non lu → mémoire passive. On ne la promeut pas.

6. Intégrité si un hash est donné : `digest == attendu` prouve les octets reconstruits. Écrire la LIM à côté, toujours.
7. Répondre avec les blocs ci-dessous. Finir par une seule prochaine porte.

Formule de travail, DÉF pas un théorème :

`M = S + I + R + V + L`

sources, index, règles, validation, lecture. Sans L, le disque reste fantôme.

## Sortie

### Plafond
Ouvert / listé / non touché. 116 et 67 : dans la passe ou hors passe.

### FAIT
Ce qui a été listé ou lu, avec id, nom, taille ou URL réellement vus.

### LIM
Pagination, corps non lus, URL non pingées, hash qui ne prouve pas la sûreté.

### DÉF
Les définitions utilisées (grade, priorité, mémoire active). Une ligne chacune.

### Priorité
Seulement les textes ouverts. Mot, compte, fichier. Pas de drapeau Willow sur un titre non lu.

### Prochaine porte
Une. Défaut estate : rouvrir `SOURCES.json` et en vérifier dix URL, pas quarante-et-une. Défaut littéraire, si l'humain n'en nomme pas : Timou `1XRBuVy5I_gAG-hv7rEgWybQdBo2SWQiYtHm-yFOSyCk`. Pas les deux.
